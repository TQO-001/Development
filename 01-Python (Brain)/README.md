# Curriculum: Python for AI & Machine Learning

---

## 1. Core Python Fundamentals (The Mechanics)

_Goal: Master the "grammar" of the language in 1 day before moving to AI-specific logic._

### **A. Data Types & Basic Operators**

- **Numerics:** Integers, Floats.    
- **Strings:** Formatting, Slicing, and Methods.    
- **Booleans:** Truthiness and comparison.    
- **Operators:** Arithmetic (`+`, `-`, `*`, `/`, `//`, `%`, ) and Logical (`and`, `or`, `not`).

### **B. Data Structures**

- **Lists & Tuples:** Mastery of indexing, slicing, and understanding mutability vs. immutability.    
- **Dictionaries:** Key-value mapping for representing data objects and configurations.    
- **Sets:** Understanding uniqueness, membership testing, and set operations (union, intersection).

### **C. Logic & Flow Control**

- **Conditional Statements:** `if`, `elif`, `else`.    
- **Loops:** Iterating over sequences with `for` and conditional repetition with `while`.

### **D. Functions & Modules**

- **Reusable Code:** Defining functions with `def`, positional/keyword arguments, and return values.    
- **Packaging:** Managing environments with `venv`, installing packages via `pip`, and using `import`.

### **E. File & API Handling**

- **File I/O:** Reading and writing `.csv`, `.json`, and `.txt` files using the `with` statement.    
- **APIs:** Using the `requests` library to interface with external services (OpenAI, Hugging Face).

---

## 2. Fundamental AI Concepts (The Theory)

_Goal: Understand the "Why" behind the algorithms._

- **Machine Learning (ML) Basics:** Transitioning from explicit rules to pattern-based learning from data.    
- **Supervised vs. Unsupervised Learning:** Training with labeled "answers" vs. discovering hidden patterns (clustering).    
- **Neural Networks:** Foundational understanding of layers, neurons, and the mechanics of "Deep Learning."    
- **Natural Language Processing (NLP):** How machines interpret, tokenize, and generate human language.

---

## 3. Core AI/ML Libraries (The Toolset)

_Goal: Proficiency in industry-standard frameworks._

- **NumPy:** High-performance numerical computing and multi-dimensional array (Tensor) manipulation.    
- **Pandas:** Data manipulation, cleaning, and analysis using DataFrames.    
- **Scikit-learn:** Implementing traditional ML algorithms (Regression, Classification, Clustering).    
- **PyTorch or TensorFlow:** Building and training deep learning neural networks.    
- **Hugging Face Transformers:** Utilizing pre-trained state-of-the-art NLP models.

---

## 4. Applied Research & SICP Bridge (The Systems Layer)

_Goal: Integrating AI into your Systems Engineering Roadmap (Doc0)._

- **Vector Embeddings:** Research how text is mathematically projected into high-dimensional space.    
- **Similarity Search:** Implementing algorithms like **Cosine Similarity** to build search/retrieval engines.    
- **LLM Tool-Use (Agents):** Designing loops where the "Brain" (Python) can execute actions via APIs or local scripts.    
- **Data Pipelines (ETL):** Designing robust **Extract, Transform, Load** processes to move data from scrapers into **PostgreSQL**.

---

> **Practical Mission:** By researching these in order, you maintain the low-level computational rigor of the "Wizard Book" while scaling up to modern AI orchestration.
